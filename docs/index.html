HEPHAISTOS

Écosystème Android modulaire sans interface • Package com.hephaistos.launcher

FR / EN • Ecosystem Spec v1.0

Comment créer les futures applications de l'environnement HEPHAISTOS

Chaque future application de l'écosystème doit porter un nom de package com.hephaistos.<module> et ne contenir aucune interface graphique. HEPHAISTOS détecte automatiquement l'APK, lit son manifeste JSON (section ui + section manual), génère son interface uniforme (Clair / Sombre / Système), fournit la popup de sélection de fichiers, le terminal intégré et les notifications de progression.

Each module also embeds a machine-readable manual (mode d'emploi) describing its commands and parameters so both HEPHAISTOS and other com.hephaistos.* modules can orchestrate each other cleanly.

Démarrage rapide — Contrat minimal d'un module

<!-- AndroidManifest.xml du module com.hephaistos.monmodule -->
<service
    android:name=".ModuleEngineService"
    android:exported="true">
    <intent-filter>
        <action android:name="com.hephaistos.action.MODULE" />
        <action android:name="com.hephaistos.action.EXECUTE" />
    </intent-filter>
    <meta-data
        android:name="com.hephaistos.module.manifest"
        android:resource="@raw/hephaistos_manifest" />
</service>
